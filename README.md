ConsoleRaft is a scalable real-time console platform, leveraging load-balancing and auto-scaling engine capabilities.

ConsoleRaft is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/ConsoleRaft.git`
2. `cd ConsoleRaft`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
